# Simple Inventory Management System

A basic object-oriented Python program for managing products in an inventory.

## Features

- Add new products
- Remove products by product ID
- Update product quantities
- Search products by name
- Calculate total inventory value
- Load inventory data from a CSV file

## Files

- `inventory.py` - Main Python program
- `sample_inventory.csv` - Sample inventory data

## How to Run

Make sure Python is installed.

Run:

```bash
python inventory.py
